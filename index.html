02 / Selected work

Ideas in progress.

I use projects to learn how different pieces of software fit together. Here is the main experiment I am documenting right now.

J.
WORK IN PROGRESS

Jarvis AI

A personal-assistant experiment exploring voice interaction and desktop workflows with Python.

PythonVoice UIAutomation concepts

What I'm exploring

01 / CONCEPT

How a voice-driven assistant might connect input, intent handling, application actions and spoken responses. The diagram in my notes is a learning model, not a claim that every feature is implemented.

What I'm learning

02 / PROCESS

Breaking the assistant into smaller parts, understanding Python modules, testing one feature at a time, and keeping track of errors instead of hiding them.

Next steps

03 / ROADMAP

Make the basic voice loop reliable, document what works, test desktop actions carefully, and add a feature only after its behaviour is understood.

Current status

EARLY STAGE

This is an evolving personal project. Meeting participation, message reading, voice authentication and other advanced ideas are not presented as finished features.

01 — METHOD

Prototype first

Start with a small behaviour that can be tested and improved.

02 — DEBUG

Learn from errors

Understand what failed before adding another layer.

03 — DOCUMENT

Show the real progress

Record lessons and limitations so the project stays honest.
